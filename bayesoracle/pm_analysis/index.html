ℹ How to read this ▼

Node label: Name · PM% / Bayes%
PM% = Polymarket crowd price. Bayes% = BayesOracle network estimate.

Node colour = divergence |Bayes − PM|. High = BayesOracle disagrees with the market.

Arrow numbers: pY / pN = P(child | parent YES) / P(child | parent NO). Blue = positive influence, orange = inhibitory, dashed = secondary.

BayesOracle formula:
P(child) = pY × P(parent) + pN × (1 − P(parent))

Root nodes (grey border) have no parents — PM price is used as the prior. Click one to set a hypothetical value with the slider.

pY/pN sources: bin = from historical price bins (≥8 days), reg = regression, llm = LLM-estimated only. Source and R² shown in the detail panel.
