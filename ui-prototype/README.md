# ui-prototype

A **standalone React/TSX design prototype** of the "Retro Analysis (בדיעבד)"
case-study presentation — a hand-built narrative UI (Venezuela 2026, War Watch
2025, …), not a data-driven view of the live atlas.

- `page.tsx` — a Next.js App Router client component (`'use client'`) that renders
  the case studies.
- `data.ts` — **hand-authored** content (`NewsItem` / `AnalysisSection` interfaces +
  an `analyses` array). It is *not* generated by the pipeline.

## Status & how it fits

- **Not built or deployed from this repo.** There is no `package.json`, `tsconfig`,
  or Next.js config here — these two files are a snippet meant to be dropped into
  the separate **Daatan** Next.js app. Nothing in CI compiles or ships them.
- **Unrelated to `truthmachine-page-generator`.** That tool writes
  `data/pages/*.json` from `data/events/` + `data/atlas/` for the live, data-driven
  UI. This prototype reads its own static `data.ts` instead — different shape,
  different purpose. Don't expect edits here to reflect atlas data, or vice-versa.
- See [`case-studies/`](../case-studies/) for the plain-HTML sibling of the same
  case-study presentation.

Treat this as a **design reference**. If it diverges from the live Daatan UI, the
live app is authoritative.
